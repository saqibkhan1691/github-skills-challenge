# AIOps Assessment – Basic AIOps Monitoring & Event Processing

## 1. Overview

This project demonstrates a basic AIOps workflow using a lightweight Python-based simulation.

The workflow monitors operational data from an application service, identifies abnormal behaviour, generates anomaly events, and processes those events through a simulated event-streaming pipeline.

The assessment demonstrates the following workflow:
